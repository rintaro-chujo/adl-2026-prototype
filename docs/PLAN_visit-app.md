# 来場者アプリ実装プラン v2 — NFC コレクション & マイリーフレット & スクリーンモード

「モノにこころをあずけておりまして / Things That Embrace your Heart」展の鑑賞体験拡張。
**確定事項**: 本番は Vercel デプロイ / プリントPCは Mac(両面印刷対応)/ ポスターPDFは40枚・全て横位置(4161×2976pt ≈ A3横比率)。

---

## 全体像

```
[NFCタグ×40(1作品1タグ・共用)] ──URL──▶ visit.html(スマホSPA)
        │ ①コレクション(スタンプラリー)…通常モード
        │ ②リーフレットモード…アプリ内ボタンで切替(同じタグを読んでも挙動が変わる)
        │     3作品選択 → 気持ち(=色)選択 → アンケート → 送信
        │     (裏でグラフィックス生成)
        ▼
  Vercel API /api/print-jobs(Vercel Blob 保存)
        ├─◀ 3秒ポーリング: プリントPC print-agent(Node)
        │     A4縦・両面PDF合成(pdf-lib) → lp で自動印刷 / survey.csv 追記
        └─◀ 5秒ポーリング: screen.html ③スクリーンモード(プロジェクター投影)
```

## NFC 設計(v1から変更: タグは1種類のみ)

- タグは作品ごとに1枚、URL `https://<domain>/visit.html#g/<work-id>` のみ。**リーフレット用の専用タグは作らない。**
- **モードはアプリ側の状態(localStorage)で持つ**: 通常=コレクションに追加+ゲット演出 / リーフレットモード中=選択スロットに追加。→「同じタグでモードによって挙動を変える」は **可能**(ユーザーの言う "localhost" は localStorage の理解で正)。
- URL遷移で開かれた場合(iOS)も、ハッシュ処理時に localStorage のモードを見て分岐するので同じ挙動。
- ノーロード設計は v1 のまま: ハッシュルーティング + Android Chrome は `NDEFReader` アプリ内スキャン(遷移ゼロ) + Service Worker プリキャッシュ + PWA。

## 機能① コレクション(v1からの変更点のみ)

- **ヒーローは常時アニメーション**: にじみ図形が絶えずウニョウニョ動く(index.html の整数周波数サイン波ループを流用、低負荷のため縮小オフスクリーンでぼかし)。
- タイトルは **左上=日本語「モノにこころをあずけておりまして」固定表示、右下=英語 Things That Embrace your Heart**。
- ほかは v1 通り(2カラム×20+セクション見出し、カードゲット演出、詳細ズーム、最下部にリーフレットボタン、localStorage)。

## 機能② マイリーフレット(大幅更新)

### フロー
1. 画面下ボタンでリーフレットモードへ。
2. **3作品を選ぶ**(NFCを3回読む or 取得済みからタップ)。1枚目が「もっともお気に入り」(スロットの★タップで変更可)。
   ※印刷レイアウトが3枚構成(A5×1+A6×2)・ビジュアルの図形も3つなので、選択数は4→**3**に変更。
3. **「今の気持ちを選んでください」**: 感情の選択肢(例: うれしい/おだやか/なつかしい/せつない/わくわく/じんわり…デザインシステムの7色パレットに対応付け)→ メインカラー決定。描画ステップは**廃止**。
4. そのままアンケートへ(回答中に裏でグラフィックスを canvas 生成)。
5. 送信 → ジョブPOST → 完了画面(出来上がりプレビュー+「まもなくプリンターから出てきます」)。

### アンケート(確定)
※「今の気持ちを選んでください」(=メインカラー選択)はアンケートの前の独立ステップ
1. ご来場のきっかけ(選択式)
2. あなたについて(選択式)
3. 展示の満足度を教えてください(5段階)
4. 展示の中でもっともこころが動いたこと・その他コメント(自由記述)

### 表面グラフィックス(★最重要・最初に実装して品質確認)
スケッチ準拠。クリーム地 `#F4EFE4` + poster.svg のタイポグラフィレイアウト(縦書き和文タイトル・英文・会期)に:
- **フニャッとした輪郭のぼやけた図形を3つ**(大1=お気に入り、小2)をランダム配置(重なり回避・タイポ回避のための配置制約付き)。形の揺らぎは控えめ(中の画像が破綻しない程度)。
- 各図形の中に**その作品PDFから抽出したメインビジュアル(ページ上で最大表示面積の画像)**をカバーフィットで入れる。
- **縁はフェザー(ぼけたアルファマスク)**、縁を中心に**選択した色をぼんやり**オーバーレイ、全体の透明度を調整してごちゃつきを抑える。
- 実装: canvas 合成(画像を図形パスでクリップ → ぼかした図形マスクで destination-in フェザー → 色のにじみリムを重ねる)。
- **1つの描画モジュールを3用途で共用**: スマホでの印刷用高解像度PNG(A4縦300ppi)/完了画面プレビュー/スクリーンモードのアニメ版。ジョブには PNG に加えて**スペックJSON(seed・色・作品ID×3・配置)**を含め、スクリーン側はスペックから再構成する。
- プロトタイプ: `graphic-lab.html`(シード・色・作品の差し替えUI付き)で品質を先に詰める。

### 印刷物(A4縦・両面)※「A4横」→A4縦に変更提案
ポスターが横位置(√2横比率)なので、**A4縦**だと隙間なくぴったり組める:
- **裏**: 上=お気に入りを **A5横(210×148)でフル(ノートリミング)**、下=残り2作品を**左半分にカットしてA6縦(105×148)を2枚並べ**(横ポスターの左半分≈A6縦比率でほぼ無トリミング)。合計3枚、210×296mm≈A4縦にぴったり。
  - ※「左半分」がタイトル側か図版側かはPDF次第→実装時に確認、左右どちらを残すかは設定フラグ化。
- **表**: 生成グラフィックス(スマホで300ppiレンダしたPNG)+ **QRコード**(`#my/<id1>,<id2>,<id3>` → サーバー不要の拡大閲覧ビュー)。
- pdf-lib で合成。裏面のポスターは元PDFページを**ベクターのまま**埋め込み。`lp -o sides=two-sided-long-edge`。

## 機能③ スクリーンモード(新規)

- `screen.html`: プロジェクター投影用フルスクリーンページ。**最新のマイリーフレットのグラフィックス(図形3つ)が常時ウニョウニョアニメーション**して表示される=展覧会のメイングラフィックス。
- `/api/print-jobs` の最新ジョブを5秒間隔でポーリング。**新しいリーフレットが作られたら、現在の3図形が「にゅーっ」と上に押し出され、新しい来場者の選択(色・3作品)による図形が下から入ってくる**トランジション。
- レンダリングはジョブ内のスペックJSON+Web用画像から(印刷用PNGは使わない)。誰も作っていない間はデフォルトのスペックをローテーション。

## 実装の進め方

   visit.html 本体 / screen.html / API+print-agent / 実機NFC検証
